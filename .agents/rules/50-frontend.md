# Frontend Rules

- Every screen includes loading, empty, error, disabled and retry states.
- Every chain action uses review, sign, confirming and completed/failed states.
- Display the Devnet badge and test-asset warning.
- Do not show success before server confirmation.
- Present AI output as advisory signals with a human-decision disclaimer.
- Keep components presentation-focused; business rules stay on the server.
- Use accessible labels, keyboard navigation and visible focus.
