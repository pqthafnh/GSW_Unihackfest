# Core Rules

## Always
- Implement only the requested scope.
- State assumptions and acceptance criteria before coding.
- List files before modification.
- Prefer the smallest vertical slice that can be tested.
- Preserve the fixed stack unless an accepted ADR changes it.
- Report failures honestly and never fabricate command output.

## Never
- Hide unfinished work behind unmarked mocks.
- Mix unrelated refactors into a feature.
- delete tests to make CI green.
- use production data or real-value assets in the MVP.
- describe a receipt as automatic legal copyright ownership.
