# Skill: Implement Feature

## Trigger
Use for an end-to-end product feature.

## Workflow
1. Read product requirement, architecture and relevant ADRs.
2. Define scope, exclusions, actors, states and acceptance criteria.
3. Identify schema, service, API, UI and test impact.
4. List files before editing.
5. Add migration first when required.
6. Implement domain rules and permissions.
7. Implement API contract.
8. Implement UI states.
9. Add unit, integration and E2E tests as appropriate.
10. Run verification and update docs/tasks.md.

## Output
Report changed files, commands, results, risks and follow-up work.
