# Skill: API Development

## Workflow
1. Define request/response Zod schemas.
2. Define authentication and authorization.
3. Identify allowed source states and target states.
4. Implement a thin route handler.
5. Implement service orchestration and repository calls.
6. Map domain errors to safe API errors.
7. Add request ID and audit events.
8. Test validation, unauthorized, forbidden, conflict, idempotency and success.
9. Update `docs/api.md`.
