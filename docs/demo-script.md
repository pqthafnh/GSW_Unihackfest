# Demo Script

## Four-minute flow
1. Explain the indie game localization problem.
2. Client creates a gig and reviews locked license terms.
3. Client funds escrow with test token on Devnet.
4. Worker uploads the dialogue file; show content hash and review signals.
5. Client approves; show settlement transaction and resulting balances.
6. Show the IP License Receipt and public safe verification page.
7. Close with validation, revenue model and roadmap.

## Fallback
Keep a recorded video, funded gig, confirmed settlement signature and existing receipt asset ready. Never edit the database manually during the demo.
