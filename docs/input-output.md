# Input and Output Contracts

## Frontend input
Brief, deliverables, deadline, license selection, budget, wallet signatures and submission file.

## Backend input/output
Input: authenticated actor, DTO and optional transaction signature. Output: typed DTO, unsigned transaction or pending status. Errors use domain codes.

## Smart contract I/O
Input: signer, PDA accounts, mint, atomic amount and hashes. Output: updated state, token movements and events.

## AI I/O
Input: minimized brief and safe submission text. Output: summary, coverage, risk flags and confidence note.

## Receipt I/O
Input: gig ID, hashes, license type and verified settlement signature. Output: asset ID, metadata URI and mint status.
