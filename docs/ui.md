# UI Specification

## Routes
Landing, login, client gig list/create/detail, worker gig list/detail, admin dispute detail and public receipt verification.

## Core components
Gig form, status badge, timeline, license summary, submission uploader, AI review panel, wallet action button, transaction modal, proof card and receipt card.

## States
Every view supports loading, empty, error, disabled, retry and unauthorized states. Chain actions show review, sign, confirming and completed/failed. Show Devnet and test-asset warnings.

## Accessibility
Use semantic labels, keyboard access, focus visibility, sufficient contrast, text error messages and non-color status indicators.
