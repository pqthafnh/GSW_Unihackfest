# Product Specification

## Problem
Indie game studios need small localization and narrative tasks completed quickly, while contributors need payment assurance and clear usage terms.

## Users
- Client: indie game studio or student game team.
- Worker: student or freelancer producing localized or narrative content.
- Admin: reviewer for disputes in the MVP.

## Value proposition
A single workflow links a clear brief, locked license terms, escrowed test payment, private submission, human review, settlement proof and a verifiable license receipt.

## MVP
Create gig, lock terms, fund escrow, assign worker, private submission, content hash, AI review signals, revision, approval, settlement, receipt and public safe verification.

## Non-goals
Legal authorship adjudication, mainnet payments, multi-chain, secondary marketplace, guaranteed royalties and decentralized arbitration.

## Success metrics
- At least five target-user interviews.
- End-to-end demo completed without manual database edits.
- At least 80% of usability testers complete the core flow.
- Zero double settlement in tests.
- One pilot-interest signal from a buyer if available.
